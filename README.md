
Health Hub is a web-based wellness platform designed to encourage a healthy lifestyle by providing resources related to fitness, nutrition, and mental wellness. It includes an interactive BMI calculator to help users understand their body mass index and explore suitable weight management goals.
Features
- BMI Calculator: Calculates BMI based on height and weight.
- Fitness: Provides fitness and exercise guidance.
- Nutrition: Offers healthy eating and nutrition information.
- Mental Wellness: Promotes mental health awareness.
- Weight Management: Provides guidance for weight gain, weight loss, and weight maintenance.
- Responsive Design: User-friendly interface accessible across different devices.
